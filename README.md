# Live Weather Dashboard

## Overview
This project is a **Live Weather Dashboard** built using **HTML, CSS, and JavaScript**.  
It allows users to search for any city and view real-time weather details instantly.

## Features
- Fetches real-time weather using OpenWeatherMap API  
- Displays temperature (°C), weather description, city name, and icon  
- Error handling for invalid city names  
- Fully client-side (no backend)  
- Responsive design for all devices  

## Technologies Used
- HTML5  
- CSS3  
- JavaScript (Fetch API)  
- OpenWeatherMap API  
- GitHub Pages for deployment  

## How It Works
- **Search:** Enter a city name in the input box  
- **Fetch Weather:** Click “Get Weather” or press Enter  
- **Display:** Shows temperature, description, icon, and city name  
- **Error Handling:** Shows message if city is invalid or empty
